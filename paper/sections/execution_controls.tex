\subsection{Minimal Execution Controls}
\label{app:execution-controls}
The procedural control generates a Python \texttt{assess(attrs)} function under the same outer admissibility, worst-value, and selection policy as Set. It is a program-aided control, not an exact reproduction of PAL or Logic.py. The primary and effort controls receive the catalogue; the matched-input control and Set compile without it. Table~\ref{tab:execution-ablation} retains the primary DeepSeek comparison, all completed effort groups, and the identical-input control. It provides the attribution check needed for this paper without treating implementation ranking as a separate research question.

\subsection{Task language}
\label{app:language}
The original study uses the same 60 identifiers for four profiles, two languages, and three methods: 1,440 outcomes. A reviewed 183-phrase map preserves identifiers, quantities, types, events, and authorization; system-level method instructions stay fixed. Table~\ref{tab:language} gives Direct/Set results on the 60-task panel and a separate 200-task Astra panel. The two panels have different task counts and are reported separately.

\begin{table*}[t]
\centering\small\setlength{\tabcolsep}{4pt}
\input{tables/appendix_language}
\caption{Language outcomes and failure partitions in one table. U/R/O denotes unsafe/false-refusal/other. Panels with $n=60$ and $n=200$ are identified separately. Figure~\ref{fig:robustness}b shows the DeepSeek subset.}
\label{tab:language}
\end{table*}

For DeepSeek low, Direct exactness decreases from 36 to 34 under translation while unsafe acceptances fall from nine to six. Set has zero unsafe acceptances in these cells; their residual errors include invalid outputs. Translation therefore affects safety and exactness differently. This controlled task-language test is neither expert linguistic annotation nor a change of the entire system language.

\subsection{Output-budget control}
\label{app:budget}
The Direct budget control pairs original output caps with a 262,144-token cap on 46 historically budget-sensitive tasks, yielding 92 new calls. Each pair uses the same 1,800-second deadline and differs only in output cap. Exact decisions increase from 10/46 to 26/46 (Table~\ref{tab:budget}). These new attempts do not overwrite first outcomes.
