\section{Introduction}
\label{sec:introduction}
An agent entrusted to purchase can commit the user to both a price and contractual consequences such as cancellation fees. Meeting a shopping objective is therefore insufficient: the commitment must stay within the authority the user granted. The Agent Payments Protocol (AP2) explicitly targets purchases under pre-approved conditions when the user is absent \citep{ap2}. Before payment execution, an agent must determine whether a proposed purchase satisfies those conditions. We study this semantic decision, with authentication and settlement outside our scope.

Existing authorization can still leave uncertainty about what a request requires or what a purchase will cost under future events. Choosing a convenient reading can permit an action the user did not authorize; refusing every uncertain request can discard useful purchases. The question is whether a valuable purchase is already justified across the retained possibilities. We study purchase or refusal without another user turn, using only existing authorization. Clarification methods obtain additional information \citep{knowno,voi,sage}; here, the agent must act within what is already permitted or decline the task.

We introduce \ours, an executable workflow that separates authorization from value. It first requires the same purchase to satisfy the hard requirements and financial permissions of every retained state, then ranks admissible purchases by worst-case utility and accepts only a positive-value option. This instantiates the fixed-set max--min principle of Risk-Averse Calibration (RAC) \citep{rac} for delegated purchasing. Utility cannot compensate for violating authorization: a loss limit restricts permission, whereas contractual compensation changes the loss itself. SET provides an explicit decision procedure and a specification whose permissions can be inspected. We study both how reliably this workflow implements the stated policy and what its successful decisions establish about the generated authorization. The optimization principle and external execution are established ingredients; the purchasing semantics and the evidence needed to assess their faithful realization are our focus.

A correct current decision does not establish that the underlying permissions are correct. An unauthorized alternative may already be admitted but lose to a higher-valued authorized offer. If the preferred offer becomes unavailable, the same specification can select the unauthorized alternative even while other authorized, positive-value purchases remain. The executor need not change its rules or receive a new model response. The false permission was already present; the original choice did not reveal it. This distinction matters whenever a delegated agent must choose among alternatives under unchanged authorization.

Our evaluation examines both useful decisions and the permissions behind them. Paired contractual-boundary tests ask whether decisions respond when a purchase crosses an authorization limit; intent tests ask whether common purchases remain possible under ambiguity. A separate frozen-specification study changes only candidate availability to test permissions that safe choices can conceal. SET improves the primary workflow, while availability changes expose hidden errors across 15 templates and all four contract families. Together, these results connect executable decision processing to its essential semantic requirement: choosing a different offer must still respect the same authorization.

The paper makes three contributions:
\begin{itemize}
\item \textbf{Useful decisions under existing authorization:} a purchase-or-refusal formulation that separates joint admissibility from worst-case value, and its realization in SET without resolving all retained uncertainty.
\item \textbf{Authorization beyond current correctness:} an analysis and controlled test of false permissions left unexamined by the selected purchase, holding generated conditions fixed and retaining viable authorized alternatives.
\item \textbf{Controlled evidence of gains and hidden errors:} multi-model boundary and intent tests of workflow reliability, followed by a prospective availability study identifying authorization failures across contract structures, including failures from exact starting decisions.
\end{itemize}
